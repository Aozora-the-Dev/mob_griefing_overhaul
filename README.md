# Mob Griefing Overhaul

Provides options for fine-tuning mob griefing
- Creeper explosions `mob_griefing_overhaul:creeper_griefing`
- Ghast Fireball explosions `mob_griefing_overhaul:ghast_fireball_griefing`
- Enderman block pickup `mob_griefing_overhaul:enderman_griefing`

Options are controlled via gamerules.
When Minecraft's normal `mob_griefing` rule is enabled, you can use the new gamerules to restrict mob griefing.
Let Ghasts continue to ravage the Nether while your garden is safe from Enderman thieves.
